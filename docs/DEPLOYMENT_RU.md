# Развертывание Chess Diagrams

Дата сборки: 18 октября 2026 года.

## Готовые файлы

ChessDiagrams-deployment.zip — production-сборка для статического хостинга.
ChessDiagrams-deployment/ — те же файлы без архива.

В корне архива находятся index.html, JS/CSS bundles, favicon.ico, 3rdpartylicenses.txt и папка pdfjs со всеми вложенными файлами. Загружайте всё содержимое, сохраняя структуру каталогов. Файлы из src, node_modules, конфигурация Angular, исходные PDF и Python-программа на сервере не нужны.

## Как развернуть

1. Распакуйте архив.
2. Загрузите его содержимое в каталог сайта, например public_html, wwwroot или подпапку chess/.
3. Настройте index.html как стартовый документ.
4. Откройте сайт через HTTP/HTTPS; для публичного размещения используйте HTTPS. Двойной клик по локальному index.html (file://) не является способом запуска.
5. Для подпапки открывайте URL с завершающим слешем: https://example.com/chess/.

Backend, Node.js и Angular CLI на production-сервере не требуются. Пользовательские PDF и изображения обрабатываются в браузере.

## Настройки хостинга

- .html: text/html
- .js и .mjs: text/javascript или application/javascript
- .css: text/css
- .wasm: application/wasm
- Остальные бинарные ресурсы PDF.js должны отдаваться как файлы, без подмены на index.html.
- Разрешите same-origin web workers и загрузку ресурсов из pdfjs/.
- Не кешируйте index.html надолго. При новой версии обновляйте все файлы; файлы с хешем в имени можно кешировать надолго. Ресурсы pdfjs имеют фиксированные имена, поэтому при обновлении PDF.js их кеш нужно обновлять или очищать.
- Пользовательских Angular-маршрутов сейчас нет; SPA-rewrite для текущего приложения не обязателен. Не перенаправляйте отсутствующие JS/WASM-ресурсы на HTML.

## Проверка после публикации

- Отображается английский интерфейс с крупными кнопками.
- PDF открывается; доски обнаруживаются; клик увеличивает отдельную доску.
- Работают переключение страниц и возврат из крупного просмотра.
- Открывается изображение PNG/JPEG/WebP.
- В Network/Console отсутствуют 404 для pdf.worker.min.mjs, worker-*.js, шрифтов, CMap и WASM; отсутствуют ошибки MIME.

## Повторная сборка

В C:\Projects\ChessDiagram\ChessDiagrams:

    npm run build -- --configuration production --base-href ./

Файлы сайта: dist\ChessDiagrams\browser\.
Дополнительно переносите dist\ChessDiagrams\3rdpartylicenses.txt.

Пути относительные: сборка подходит для корня сайта и подпапки. Этот пакет подготовлен локально; публикация на внешний сервер не выполнялась.
